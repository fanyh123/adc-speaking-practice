# ADC Speaking Practice

A mobile English speaking practice page.

The lesson is encrypted before publication. The passphrase is distributed separately.

Open the HTTPS GitHub Pages URL in Safari on iPhone. No API key is required.

An encrypted neural-voice comparison page is available at `voice-samples/`.
It contains three locally generated Kokoro-82M v1.0 samples (Apache 2.0 model).
The samples use the same separately distributed passphrase as the lesson.

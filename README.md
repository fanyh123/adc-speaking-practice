# ADC Speaking Practice

A mobile English speaking practice page.

The lesson is encrypted before publication. The passphrase is distributed separately.

Open the HTTPS GitHub Pages URL in Safari on iPhone. No API key is required.

The full lesson defaults to locally generated Kokoro Heart FP32 audio: sentences,
questions, sentence chunks, words and glossary terms. No denoising is applied.
Audio files are AES-GCM encrypted with an independent random key kept inside
the passphrase-encrypted lesson. Public filenames contain no transcript.
Personalized text uses the device voice and is labeled accordingly.

An encrypted neural-voice comparison page is available at `voice-samples/`.
It contains three Microsoft neural voice samples generated from neutral example sentences.
The private meeting lesson was not submitted to the voice service.
The samples use the same separately distributed passphrase as the lesson.

`kokoro-clean/` compares an original Kokoro Heart recording with a lightly
processed version. Both clips and their transcript are encrypted before publication.
